## 目标
我们要实现一个功能，读取erp数据的pg实现和图实现方法支持多套不同的数据结构

## 背景
我们当前实现erp查询功能是以oracle ebs为主的postgresql和图查询，但我们可能还存在另外一套数据库或者图结构以另外一种结构存在。我希望在不动上层架构的情况下，对两套数据源进行兼容，让agent能适配多套数据源。

## 实现思路
在erp查询的tools方法里，根据开关使用不同的实现方法，对tools以外的方法调用无感知。或者可以考虑类似java spring框架的依赖注入方式，注入什么实现就读什么结构，读外部调用是统一的
